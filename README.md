# Bask Health — Responsive Healthcare Landing Page

A fast, responsive, and accessible modern landing page built for a digital healthcare platform, emphasizing semantic HTML5, modern CSS grid architecture, and performance.

## Key Features
- **Semantic HTML5:** Clean DOM hierarchy (`<header>`, `<nav>`, `<section>`, `<details>`, `<footer>`) optimized for accessibility and SEO.
- **CSS Architecture:** Uses CSS variables, Flexbox, and CSS Grid for a fluid mobile-first responsive layout.
- **Interactive UI:** Built-in FAQ accordion using native `<details>`/`<summary>` elements without third-party dependencies.
- **High Performance:** Zero framework overhead, vanilla code for instant load times.

## Tech Stack
- HTML5 / CSS3 (Grid & Flexbox)
- Git / GitHub
