# Bask Health — Responsive Healthcare Landing Page 🩺

A fast, fully responsive, and accessible landing page designed for a digital healthcare platform. Built strictly with vanilla **HTML5** and **CSS3**, focusing on clean semantic architecture, native interactive elements, and zero external dependencies for optimal performance.

---

## 🚀 Key Features

- **Semantic HTML5:** Structured with standard elements (`<header>`, `<nav>`, `<section>`, `<article>`, `<details>`, `<footer>`) to maximize accessibility and SEO.
- **Modern CSS Architecture:** Built using CSS variables (custom properties), CSS Grid, and Flexbox for a fluid mobile-first responsive layout.
- **Native Interactive UI:** Functional FAQ accordion using native HTML `<details>` and `<summary>` tags without needing JavaScript or third-party libraries.
- **High Performance:** 100% vanilla code with zero external frameworks or heavy assets, ensuring instant load times and lightweight footprint.
- **Fully Responsive:** Smooth cross-device layout adaptation using modern CSS breakpoints and `clamp()` typography.

---

## 🛠️ Tech Stack

- **Markup:** HTML5 (Semantic & Accessible)
- **Styling:** CSS3 (CSS Variables, Grid, Flexbox, Media Queries)
- **Version Control & Hosting:** Git, GitHub

⚙️ Quick Start (Local Setup)
No build tools, package managers, or local server environments are required.

1. Clone the repository
Bash
git clone [https://github.com/santisazalema/bask-health-landing.git](https://github.com/santisazalema/bask-health-landing.git)
cd bask-health-landing
2. Run the project
Simply double-click the index.html file to open it directly in any modern browser, or launch it with a lightweight server:

Bash
# Using Python (optional)
python3 -m http.server 8000

# Or using PHP (optional)
php -S localhost:8000
